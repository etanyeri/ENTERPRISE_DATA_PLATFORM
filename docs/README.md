# Enterprise Data Platform Documentation

This repository demonstrates an end-to-end enterprise data platform built using Snowflake, dbt, SQL, and Terraform, with a focus on data ingestion, transformation, dimensional modeling, and data quality.

## Repository Purpose

The purpose of this repository is to demonstrate enterprise data engineering practices, including standardized development rules, naming conventions, data modeling principles, and maintainable analytics pipelines.

## Understanding the Repository

The documentation in this folder helps readers understand the repository structure, the purpose of its files and models, data flow between layers, architectural decisions, and recommended engineering standards.

## Documentation

- **ARCHITECTURE.md** — Platform architecture, data flow, and component responsibilities.
- **DATA_ENGINEERING_STANDARDS.md** — SQL development, dbt modeling, and engineering best practices.
- **NAMING_CONVENTIONS.md** — Standardized naming rules for models, tables, columns, and files.
- **DATA_QUALITY_STANDARDS.md** — Data validation, testing, and reliability guidelines.
- **MODELING_DECISIONS.md** — Dimensional modeling design choices, relationships, and trade-offs.
